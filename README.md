# FOCUSLY — Student Productivity Hub

A responsive student planner built with Python, Flask, SQLAlchemy, HTML, CSS and JavaScript.

## Features
- Dashboard with pending/completed/overdue task stats
- Add, complete, filter, and delete tasks
- Assignment, practical, study, and other task types
- Exam countdowns and syllabus progress
- Focus timer with focus and break modes
- Dark/light theme preference saved in your browser
- SQLite for local development; PostgreSQL via `DATABASE_URL` for hosted deployment
- Responsive layout for iPhone and desktop

## Run locally
1. Install Python 3.11+.
2. In this folder run:
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
3. Open `http://127.0.0.1:5000`.

## Deploy from iPhone with GitHub + Render
You can do the setup from Safari. The easiest path is to upload this project to a GitHub repository, then connect the repository to Render.

1. Extract `focusly_student.zip` in the Files app if needed. If using GitHub's website on iPhone, create a repository named `focusly-student` and use **Add file → Upload files** to upload the files and folders from the extracted project. Make sure `app.py`, `requirements.txt`, `Procfile`, `render.yaml`, `templates/`, and `static/` are at the repository root.
2. Sign in to Render and choose **New → Blueprint** (or create a Web Service from the repo if Blueprint is unavailable).
3. Connect the GitHub repository. The `render.yaml` blueprint defines the Python web service and a PostgreSQL database.
4. Review the plan and any pricing before creating resources. Render plans and database availability/pricing can change.
5. Wait for deployment to finish, then open the `onrender.com` URL shown by Render.
6. Test by adding a task, refreshing the page, and confirming it remains saved.

## Important notes
- Do not commit secrets or passwords.
- `SECRET_KEY` is generated by Render in the included blueprint.
- The included Render blueprint requests a small PostgreSQL plan; check the current price and availability before deploying.
- This starter version does not include user accounts. The hosted URL is not private: anyone who can access it may be able to view or change the same shared task list. Do not put sensitive personal information in it. Add authentication before using it as a private multi-user app.
- Browser theme preference is stored locally on each device. Tasks and exams are stored in the server database.
